TinkerBelle is not released. There is no build to download for any platform, and this entry is here so the changelog says so plainly.

## What exists

- The session engine that runs a snippet against a booted Stacks app. It shipped in Stacks 0.75.541 and is what `buddy tinker --serve` speaks. State remains between runs.
- A loader that runs a snippet on a remote target without writing a file there. So far it has been tested through a local pipe, not yet over a real SSH, Docker or Kubernetes connection.
- A proof that the TypeScript language server can complete against an app's models and config from inside the editor.
- A proof that the desktop window can stream results from the local agent.

## What does not exist yet

- The app itself. The editor, the result views and the target manager are being built.
- Builds for macOS, Windows or Linux.
- Checkout and licenses. The prices on the pricing page are decided, and nothing is for sale.

## What the first beta will be

A 0.x release for macOS, Windows and Linux together, with local projects, the sandbox and the remote targets: SSH, servers deployed with `buddy deploy`, Docker and Kubernetes. Each build after that gets its own entry here.
